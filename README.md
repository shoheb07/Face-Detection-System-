# Face Detection System

## Project Overview

The Face Detection System is a real-time computer vision application developed using Python and OpenCV. It detects human faces through a webcam and displays rectangles around detected faces.

The project uses Haar Cascade Classifier for face detection.

# Features

- Real-time face detection
- Webcam support
- Face highlighting
- Fast and efficient detection


# Technologies Used

- Python
- OpenCV


# Installation

## Step 1

Install OpenCV:

pip install opencv-python


# Run Project

python face_detection.py


# How It Works

1. Capture webcam video
2. Convert frames to grayscale
3. Detect faces using Haar Cascade
4. Draw rectangles around faces
5. Display output screen
